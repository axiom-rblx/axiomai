## About

Axiom AI is an AI-powered development tool built for Roblox creators.

It helps developers with scripting, UI design, debugging, code improvements, and other parts of building a Roblox project.

Axiom is focused specifically on Roblox development, giving developers a faster and easier way to build, fix, and improve their projects.

## Features

- Roblox scripting assistance
- UI design help
- Script debugging
- Code improvements
- Code explanations
- Roblox-focused AI responses
- Fast and simple interface
