## About

**Axiom AI** is an AI development workspace built for Roblox creators.

Instead of being a general-purpose chatbot with Roblox added on top, Axiom is designed around real Roblox development workflows — including Luau scripting, UI/UX, debugging, project architecture, networking, persistence, security, and Roblox Studio.

Axiom combines AI inference with its own routing, project memory, validation, and development tools to help turn an idea, error, or existing script into something usable.

---

## What Axiom Can Do

- Write and improve Luau scripts
- Debug Roblox errors and broken systems
- Design and build Roblox interfaces
- Explain unfamiliar code
- Review client/server architecture
- Help secure RemoteEvents and RemoteFunctions
- Improve performance and code structure
- Work with multi-script systems
- Remember project context
- Generate Roblox Studio changes
- Review generated code for common Roblox API mistakes

---

## Axiom Models

Axiom includes multiple profiles designed for different development workflows.

| Model | Purpose |
| --- | --- |
| **Axiom AI** | Balanced Roblox development assistance |
| **Axiom Sol** | Fast scripting and everyday development |
| **Axiom Terra** | UI/UX and interface design |
| **Axiom Work** | Higher-quality project work and deeper review |
| **Axiom Code** | Advanced engineering and larger coding tasks |

The profiles share Axiom's core runtime while changing how tasks are routed, reviewed, and handled.
