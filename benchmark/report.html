How it’s scored

Every answer is scored out of 100 by the same code, whichever tool wrote it:

  • Compiles (25): every Luau code block parses — no missing ends, unclosed brackets or broken strings. A cut-off answer doesn’t compile.
  • Real APIs (25): every Roblox class, service, property, method and enum is checked against Roblox’s published API. Each invented one costs 8 points.
  • Safe & efficient (20): security and performance checks — trusting values sent by the client, loadstring, loops that never yield, heavy work every frame. Serious problems cost 10, minor ones 3.
  • Does the job (30): the answer contains what the task asks for (for example BindToClose for a save system). Required answer patterns are listed with each task.

The first three are earned in proportion to “Does the job”, so clean code that ignores the task can’t score well.

Fairness. Every tool gets the identical prompt in a fresh chat, and its first full answer is scored with no follow-ups or edits. Only tools that answered at least tasks are ranked. Axiom checks its own answers for the first three criteria before replying, so it is designed to do well on them; “Does the job” is neutral. Automatic checks can’t judge everything — a human-rated comparison is a good next step.
